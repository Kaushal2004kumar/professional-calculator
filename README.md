# 🧮 Professional Calculator

A modern and responsive calculator built using **HTML, CSS, and JavaScript**.

The project focuses on a clean user interface, keyboard support, animations, button interactions, and basic arithmetic operations.

---

## 🚀 Features

- ➕ Addition
- ➖ Subtraction
- ✖️ Multiplication
- ➗ Division
- 🔢 Decimal number support
- 🧹 Clear (`C`) functionality
- ⌫ Delete (`DEL`) functionality
- 🟰 Calculate result using `=`
- ⌨️ Full keyboard support
- ↵ Enter key works as `=`
- ⌫ Backspace works as `DEL`
- ⎋ Escape works as `C`
- 🚫 Prevents multiple operators
- 🚫 Prevents multiple decimal points
- ✨ Button press animations
- 💡 Hover effects
- 🌈 Animated gradient on the `=` button
- 🌌 Animated professional background
- 📱 Responsive design
- 🎨 Modern dark professional UI

---

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)
- DOM Manipulation
- Event Listeners
- CSS Animations
- CSS Grid
